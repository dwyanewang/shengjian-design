# 打磨记录 · 方向 2「一个字一件事」

文件：`design-demos/dir-2.html`（源分块在 `dir-2/src/`，`dir-2/src/build.sh` 拼成单文件）。截图：`shots/dir-2/round-1/`、`round-2/`、`round-2-390/`（390 宽）、`clicks/`（点击测试）。

## 冒烟（round-0，没留图）

第一次截图后先修了一些明显的坏处，算 bug，不算打磨：按钮文字默认左对齐（分段控件、格式格子里的字全贴左）；首页「铃」大方块里巨字压住「做铃声」和试听按钮；「配」「剪」「更多来源」的说明溢出；在线音色卡片的用途文字压在试听键下；曲目封面裁得太狠，看起来像乱码；功能覆盖图的字标签重复了一遍字本身。另外把系统说明从左栏挪成通栏，左栏不再拖出一大块空蓝。

## 第 1 轮（round-1 → round-2）

看图时按 polish-loop 的八个问题过了一遍，最伤的三处：

1. **首屏没有声音（第 1 问、第 2 问）**。1600×1000 的第一屏只有标志、大标题、汉字墙和半屏「铃」。主角素材里的「波形」不在首屏，「立刻能听到的结果」只是手机里一个小按钮。
   改：在标题下面加「先听一个结果」。用白色画出《晚风》整首的包络，副歌 2:05–2:35 用实心白加框标出来，标注「来电铃声」。点方块会真的走播放头。现在首屏有声音的形状，也有一个能点的结果。

2. **手机里蓝色太多，主次不清（第 4 问）**。「净」这一屏有三个开关、三个字块和一个主按钮，全是刃蓝。眯起眼看分不出先点哪个，违反「一个状态只有一个最显眼的东西」。
   改：开关打开时改用墨色，行首的字块一律浅底。刃蓝只留给主按钮、选区和当前这件事的角标。

3. **工作台选区和标记挤在一起，概览视窗看不见（第 5 问）**。初始选区在 0:00–0:02.6，「2.6 秒」标签和「开讲」标记叠在一起；概览条里 40 秒的视窗只有 3 像素宽。
   改：初始选区改到第一处长停顿 0:11.8–0:13.4，标签写「停了 1.6 秒」。停顿看得见，也说清了为什么选它。概览视窗最少 16px。

## 交付前的检查

- **390 宽**：第一次截图时左右被裁，因为三栏的固定宽度压过了窄屏规则。改成窄屏时整栏 100% 宽，手机按屏宽缩放，标签贴齐。之后页面宽 390，没有横向溢出。
- **点击测试**（`dir-2/clicktest.mjs`，真实鼠标事件）：34 项全部通过，页面错误 0。覆盖：首页「铃」走完设成铃声；「剪」说一句，到计划，再应用；首页右上「会员」；覆盖图点 A9、C5、G7 跳到对应手机；在「配」里选了在线音色弹出会员，再退回用手机自带的；点状态栏下拉通知栏。
  测试中发现并修好了：会员弹层第二个按钮溢出屏外；状态栏中间的打孔挡住点击；从覆盖图跳回同一屏时，页面状态不重置。
- **design_lint.py**：跳过。它要求 Python 版 playwright，本机装不上：没有 pip / ensurepip，uv 的 shim 也没配置。
  改用同一台 Chrome 跑了一个简化检查，查字号底线、对比度、全大写小标签、尾巴箭头和裂图。查出两处真问题：音色区的「会员」标签、会员方案上的「最划算」，都被上层样式改成了深底灰字。另有板面上 12–13px 的刻度和覆盖图里的小字块。这些都已修好。
  剩下 5 处报警是误报：opacity 0 的隐藏元素，或白字压在兄弟层的色块上，用的不是祖先背景。黄灯类（全大写、尾巴箭头）为 0。
- 还有一处 React 警告：设置行里按钮套按钮。已改成 div。

## 没做好的（下一轮再磨）

- 曲目封面是「曲名首字裁进方块」。像「红」「山」这种字裁出来有点碎，应该按字形挑裁切位置，或者加第二种构图。
- 板面第二段（剪 / 说一句 / 导出）三台手机下面的注释，还是「竖线加一段话」，比较平。可以改成从手机里某个控件引出的标注线。
- 半屏巨字的裁切是每个字手调的偏移，「配」裁掉右半以后有点像「酉」。
