# 方向 1 打磨记录（说一句，落在声音上）

截图：`shots/dir-1/round-1/`（改前）、`shots/dir-1/round-2/`（改后）、`shots/dir-1/round-2-narrow/`（390 宽）、`shots/dir-1/clicks/`（点击测试各检查点）。

## 第 0 轮：初次渲染后先修掉的结构问题（不算打磨轮）

- 首屏全是标题和特写，第一屏看不到一台手机：把会员说明从标题区挪到第三排手机上方（那一排就是收钱的屏），标题压成两行，流程标题和说明并排；第一屏现在能看到三台手机的上沿。
- 计划页的原句在短语中间断行（「删掉长停｜顿」），手机里的连线穿过下一行字：原句改成只在标点处断行（`word-break: keep-all`），计划页字号 26（英文长句 23）；手机里去掉连线，改成「点一个短语或一张卡，其余几步的颜色变淡」。连线只留在展示板的放大特写里，那里版式是为连线排的。
- 特写的尾部波形超出白底；390 宽下标题区被特写撑到 932 宽：按内边距量宽度，网格列改成 `minmax(0, 1fr)`。

## 第 1 轮：最伤的三处

1. **工作台（第 3 台）的波形是一整块黑**：130 秒压在 328 像素里，没有纹理，「这一版来自你说的」那几处彩色痕迹几乎看不见，签名处在最常用的屏上断了。
   改：默认放大到约 28 秒，用 2 像素竖条画出音节纹理；被删掉的停顿接缝画成粉色荧光条加一根细线和顶部圆点，点一下说「这里删了一处长停顿，来自你说的『删掉长停顿』」。
2. **功能覆盖图往下是三屏一模一样的白卡片**：好查但不好看，也看不出九台手机各管多少。
   改：上面加一张「方块图」，九组方块就是九台手机，每块一项功能，指着显示名称和路径、点一下切手机；下面的逐项清单去掉卡片底，改成细线分组的索引。
3. **降噪（第 5 台）的前后对比读不出来**：「原来的」被整体压淡，看上去反而比降噪后更小声；底噪在 20 秒全景里只是一条细边。
   改：放大到 0:08–0:16（中间正好一处停顿），开平方显示让底噪成为看得见的毛边，在两条波形上直接标「这层毛边是底噪」「停顿里安静了」，未选中的一条只降到 55% 不透明。

顺手：计划页焦点外的步骤卡短语也变淡；首页一句话框里写出结果「听懂了 4 步，会短 17 秒」；分段控件文字居中；列表行标题和说明分两行；被弹层盖住的手机不再画连线圆框。

## 交付前检查

- 点击测试 `dir-1/click-test.mjs`：23 项全过（说一句 → 计划 → 应用 → 整条撤销；改数字；导出选设成铃声并完成；在线音色 → 会员说明 → 会员页 → 登录 → 试用；AI 改写；工具里降噪并存新版本；录音；深色；覆盖图跳手机并滚到位；波形拖选后剪掉），页面错误 0。
- `design_lint.py check`：本机没有 Python 版 playwright，脚本会跳过；改用它自己的测量脚本（`COLLECT_JS`）经 CDP 在 1440×900 和 1600×1000 下跑，再用它的 `judge()` 判：红灯 0、黄灯 0（修过一处：会员页价格说明 13px → 14px）。外观指纹需要截图色板，这条路拿不到。
- 390 宽：无横向溢出，手机竖排，连线隐藏。
- 英文：加了「Cut the first 3 s, remove long pauses, a bit louder, fade out 2 s at the end」作为能说的一句（试试这样说里），荧光笔跨行续上，四个短语落在同样的位置。检查时发现英文短语用了中文的字符位置，已修；数字和单位之间用不换行空格。

# 打磨记录 · 方向 2「一个字一件事」

文件：`design-demos/dir-2.html`（源分块在 `dir-2/src/`，`dir-2/src/build.sh` 拼成单文件）。截图：`shots/dir-2/round-1/`、`round-2/`、`round-2-390/`（390 宽）、`clicks/`（点击测试）。

## 冒烟（round-0，没留图）

第一次截图后先修了一些明显的坏处，算 bug，不算打磨：按钮文字默认左对齐（分段控件、格式格子里的字全贴左）；首页「铃」大方块里巨字压住「做铃声」和试听按钮；「配」「剪」「更多来源」的说明溢出；在线音色卡片的用途文字压在试听键下；曲目封面裁得太狠，看起来像乱码；功能覆盖图的字标签重复了一遍字本身。另外把系统说明从左栏挪成通栏，左栏不再拖出一大块空蓝。

## 第 1 轮（round-1 → round-2）

看图时按 polish-loop 的八个问题过了一遍，最伤的三处：

1. **首屏没有声音（第 1 问、第 2 问）**。1600×1000 的第一屏只有标志、大标题、汉字墙和半屏「铃」。主角素材里的「波形」不在首屏，「立刻能听到的结果」只是手机里一个小按钮。
   改：在标题下面加「先听一个结果」。用白色画出《晚风》整首的包络，副歌 2:05–2:35 用实心白加框标出来，标注「来电铃声」。点方块会真的走播放头。现在首屏有声音的形状，也有一个能点的结果。

2. **手机里蓝色太多，主次不清（第 4 问）**。「净」这一屏有三个开关、三个字块和一个主按钮，全是刃蓝。眯起眼看分不出先点哪个，违反「一个状态只有一个最显眼的东西」。
   改：开关打开时改用墨色，行首的字块一律浅底。刃蓝只留给主按钮、选区和当前这件事的角标。

3. **工作台选区和标记挤在一起，概览视窗看不见（第 5 问）**。初始选区在 0:00–0:02.6，「2.6 秒」标签和「开讲」标记叠在一起；概览条里 40 秒的视窗只有 3 像素宽。
   改：初始选区改到第一处长停顿 0:11.8–0:13.4，标签写「停了 1.6 秒」。停顿看得见，也说清了为什么选它。概览视窗最少 16px。

## 交付前的检查

- **390 宽**：第一次截图时左右被裁，因为三栏的固定宽度压过了窄屏规则。改成窄屏时整栏 100% 宽，手机按屏宽缩放，标签贴齐。之后页面宽 390，没有横向溢出。
- **点击测试**（`dir-2/clicktest.mjs`，真实鼠标事件）：34 项全部通过，页面错误 0。覆盖：首页「铃」走完设成铃声；「剪」说一句，到计划，再应用；首页右上「会员」；覆盖图点 A9、C5、G7 跳到对应手机；在「配」里选了在线音色弹出会员，再退回用手机自带的；点状态栏下拉通知栏。
  测试中发现并修好了：会员弹层第二个按钮溢出屏外；状态栏中间的打孔挡住点击；从覆盖图跳回同一屏时，页面状态不重置。
- **design_lint.py**：跳过。它要求 Python 版 playwright，本机装不上：没有 pip / ensurepip，uv 的 shim 也没配置。
  改用同一台 Chrome 跑了一个简化检查，查字号底线、对比度、全大写小标签、尾巴箭头和裂图。查出两处真问题：音色区的「会员」标签、会员方案上的「最划算」，都被上层样式改成了深底灰字。另有板面上 12–13px 的刻度和覆盖图里的小字块。这些都已修好。
  剩下 5 处报警是误报：opacity 0 的隐藏元素，或白字压在兄弟层的色块上，用的不是祖先背景。黄灯类（全大写、尾巴箭头）为 0。
- 还有一处 React 警告：设置行里按钮套按钮。已改成 div。

## 没做好的（下一轮再磨）

- 曲目封面是「曲名首字裁进方块」。像「红」「山」这种字裁出来有点碎，应该按字形挑裁切位置，或者加第二种构图。
- 板面第二段（剪 / 说一句 / 导出）三台手机下面的注释，还是「竖线加一段话」，比较平。可以改成从手机里某个控件引出的标注线。
- 半屏巨字的裁切是每个字手调的偏移，「配」裁掉右半以后有点像「酉」。

# 打磨记录：方向 3「竖着的声音」

文件：`design-demos/dir-3.html`（由 `dir-3/src/*.jsx` 经 `dir-3/build.mjs` 编译内联；改源码后 `node dir-3/build.mjs`）。
截图：`shots/dir-3/round-1/`（初稿）、`shots/dir-3/round-2/`（打磨后，1600 宽）、`shots/dir-3/round-2-narrow/`（390 宽）。

## 第 1 轮（初稿 → 打磨）

逐张看了 round-1 的 screen-01…07，又用 `dir-3/tour.mjs` 把覆盖图 93 项逐项点开、各截一张手机，拼成联系表看。

先修的是会让手机"坏掉"的 bug（不算三处之一）：
- 嵌套的 `span` 被 `display:block` 规则吃掉：工作台副标题拆成两行、VIP 角标被拉成整行宽的条。改成只对直接子元素生效。
- 提示条（toast）压在底部"说一句"上 4 秒，点不到输入框（点击测试就是这么发现的）。移到工具条上方。
- 晚风的副歌面板高度不够，"设成铃声"被手势条挡住一半；配乐面板同样。加高。
- 缩放胶囊常驻右上角，盖住脊线旁的标注。改成缩放时或鼠标移上去才出现。
- 按钮里套按钮（"我的"登录行、录音列表"接着录"）报 DOM 嵌套警告。

### 最伤的三处

1. **处理工具的前后对比几乎看不出差别**（降噪屏，必须出现的屏）。左半边原来、右半边降噪后，但底噪只有 0.045，左右两半长得一样，"前后差异直接画在脊线上"这件事没成立。
   改：左半边把"会被去掉的那部分"涂成琥珀色（右半边是处理后的青色）；镜像模式下用 a^0.5 的显示曲线把底噪放大到看得见；旁边加一句人话标注「琥珀色的毛刺是空调声，会去掉」，并把视图停在 0:00 那段只有环境声的地方。修复工具同用这套。
2. **"配乐是并排的第二条脊线"在展示板上完全看不到**（方向卡的核心机制之一，只有在工作台点"配乐"才出现）。
   改：左栏首页手机下面加一块特写：人声脊线和「晚风」脊线并排，说话时音乐那条变细、停顿时回来，带一个能点的"说话时音乐自动让开"开关；同时把右栏空出的位置给了"竖着输给横着的地方"说明，三栏高度也平衡了。
3. **一句话计划屏装不下计划**（必须出现的屏）：第 3、4 步被切掉，脊线顶部 ①③ 标签和"只有环境声"标注叠在一起。
   改：计划面板加高并压缩每步行距，4 步全部可见；"整体大 3 dB"的琥珀竖线挪到胶囊左侧，③ 标签不再和 ① 抢 0:00 那一点；上标改为 12px。

顺手的两处层级调整：工作台的首次提示从白底改为深底琥珀描边（原来它比脊线还亮，抢了主角）；波形加了一道更亮的芯，读起来像光而不是条形码。

## 英文界面检查（协调者追加的约束）

`dir-3/en-check.mjs` 把工作台上的标注、工具条、"说一句"、提示都换成英文后截图（不交付英文屏）：
- 脊线旁的标注列原本 126px，开配乐时只剩 76px，"Pause 2.2 s" 的 s 掉到下一行。改：配乐时两条脊线收窄、标注列放宽到 120px；所有标注允许在列宽内换行；数字和单位之间用不换行空格（`secU`）。改完两种状态都没有溢出。
- 工具条是横向滚动的胶囊，英文词长只影响滚动长度；"说一句"是单行省略。
- 没有只在中文里成立的结构：展示板和手机里都没用竖排文字，"竖着"指的是时间轴方向，与文字方向无关。
- 工作台标题长名字（「播客第 12 期 · 和王老师聊阅读」）拆成标题加副标题，不再截在半个词上；这一点英文下更需要。

## 检查结果

- 点击测试 `dir-3/test.mjs`：18 项全过（滚动、拖动滚动、横划合上停顿、撤销、说一句→4 步计划→应用为一步、会员页、先登录再订阅、导出选设成铃声、副歌→铃声、覆盖图跳手机、捏合缩放），页面错误 0。
- 截图脚本：1600 宽与 390 宽都 0 错误，390 宽 docWidth = 390，没有横向溢出。
- `design_lint.py check`：本机缺 Python 版 playwright，脚本自己跳过。改用 `dir-3/lint.mjs` 通过 CDP 跑它原样的页面探针（`lint-probe.js` 从 design_lint.py 逐字复制）和同样的阈值：
  - 初次：红灯 2 类（13px 的长说明文字 10 处；隐藏的缩放胶囊被算成对比度 1:1）。改：说明文字统一 14px；隐藏时用 visibility 而不是只靠透明度。
  - 最终：红灯 0。黄灯只剩「 · 」6 处，全部来自共用演示数据里的音频名和来源（如「广场舞串烧 · 6 首」），是内容不是装饰，没有改数据；我自己写的文案里没有用「 · 」。

## 还没做好的

- 录音页待机时下半屏是空的，只有一行提示。
- 曲目封面、音色声纹是程序生成的；原型不出声，试听只有播放头在动。
- 多轨、串烧、循环三个工具页是静态示意，拖动换顺序 / 改起点没有做成真能拖。
- 横屏没有做（竖着在横屏和平板上会浪费宽度）。
