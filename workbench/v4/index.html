  4. 4点「音乐」，选一首：音乐成为下面一轨，有人说话的地方自动变小。点那一轨，工具换成这一轨的。
  5. 5「说一句」→ 点一个例子：要改的地方画在波形上，勾掉不要的步骤，点「应用」一次改完。
  6. 6右上「导出」：设置出现在工具上面，点「导出」，系统存文件；不导了点「取消」。

这一版的工作台

工作台就是这段声音。上面是声音，紧贴着它是播放；下面的托盘里，点到什么，就是能对它做的事，一层也不用退。调的时候声音一直在上面、一直能听；做过的每件事都留在声音上，随时改、随时撤。

  1. 声音在上，播放紧贴在它下面声音的高度有上限，不会把下面挤扁；紧贴着它是播放这一条：时间、播放、撤销重做，位置固定（只有导出、一句话这类要读的事会向声音借高度，播放条跟着上去，收起就回来）。工具在最下面的托盘里，和播放之间留着空。
  2. 工具一层也不用退最下面一排是「说一句」和五个分类（常用、剪辑、声音、添加、更多），上面是这个分类的全部工具，一行 6–7 个。点一个要调的工具，它亮起来，设置出现在工具上面；再点它、点别的、或系统返回就收起。
  3. 调的东西改了就算；没有版本，只有一条历史力度、音量、淡化边调边听，收起就留着，撤销一步收回；要去掉就点它自己的「去掉」。只有真正等你拍板的事才有写着字的按钮，旁边总有写着字的出路：应用 / 不改了、导出 / 取消、完成 / 不要了、放这里 / 放回去。
  4. 波形两边留给系统在波形上选、拖都是滑动，而从屏幕边上开始的滑动是系统返回。所以声音的开头、结尾在整体视图里离边 40 dp，波形上能拖的东西离边至少 32 dp，拖到开头、结尾靠吸附。底栏和标题栏照常用满宽度。

4说明

规则（每个画面都照这个做）

从上到下

标题栏；声音；紧贴着它的播放条（时间、播放、撤销重做）；空隙；最下面的工具托盘（开着的设置、这个分类的工具、「说一句」和五个分类）。360×780：标题栏 52 dp、声音 332（含 22 的时间刻度）、播放条 76、托盘最多 320，不开设置时约 220，上面空出约 100。390×844：52、388、76、托盘最多 328。声音的高度只跟屏幕高度和轨道数有关（屏幕高的 46%、至多 400，每条轨道加 64，总要给托盘留出 320），不跟下面的工具变：在每个状态、每个分类、每个改声音的设置里，播放键都在同一个位置。比托盘高的设置（效果、声道）在托盘里自己滚动，按钮钉在下面，下沿淡出表示还有。只有几件要读、要填、要拍板的事（导出、一句话和它的计划、朗读、字幕配音、克隆音色、插入音频）先向声音借高度，最多借到声音只剩 150（含刻度），播放条跟着声音一起上去、仍在正中，收起就还回去；借了还不够才在托盘里滚。360×780 导出并展开音质：声音 150，播放条从 390 升到 208；390×844：声音 193。工具和分类一直看得见，什么都不盖住。

工具

每个至少 50 dp 宽（字号 1.3 时 60 dp）：360 dp 宽一行 6 个，390 dp 宽 7 个。不开设置时，一个分类的工具全部摆出来（两行，字号 1.3 时三行），不用横滑；开着设置时收成一行，亮着的那个在视野里，后面的露出半个。没有返回键：分类是平的，点哪个就是哪个；开着的设置靠再点亮着的工具、点别的、或系统返回收起。第一个分类跟着你点的东西变：常用 / 选中的 / 片段 / 轨道 / 标记。

设置

设置不是决定：改了就生效、马上能听，收起就留着；同一次打开里连续调整算历史里的一步，撤销一次收回；贴在声音上的设置用它自己的「去掉」拿掉。只有真的在等你拍板、又没法边做边看的事才有写着字的按钮，而且出路也写着字、就在旁边：应用 / 不改了（一句话）、导出 / 取消、完成 / 不要了（录音）、放这里 / 放回去（移动）。生成（朗读、字幕）、删掉 N 处（停顿）、只留这段 / 做铃声（副歌）、保存为音色是动作，不想做就再点一下亮着的工具。系统返回永远先收起最里面的那个。

波形的两边

两边各 24 dp 归系统的返回手势：从那里开始的滑动不给工作台。这只关系到波形，因为在波形上选、拖都是滑动：波形上能拖、能点的东西（选区圆点、标记、音量曲线的点、全局条、标签）触点范围离边至少 32 dp；整体视图里声音的开头和结尾离边 40 dp。选到开头、结尾靠吸附，手指过了开头或结尾就算到了；放大时拖到离边 64 dp 以内，画面自己往那边滚。按钮离边近没关系：点一下不是滑动。标题栏和底栏照常用满宽度，底栏在系统导航条上面。

对产品模型的要求（规划用）

  • 一个工程可以有多个源：原始音频、每次录音、朗读、插进来的别的音频、空白，都是工程里的不可变文件；主线的片段可以引用任何一个。跨音频粘贴因此变成普通的时间线修改。
  • 轨道：主线下面最多 7 轨。每轨的片段锚在主线的源帧上（像今天的标记），主线剪掉前面的内容，下面的音乐跟着对齐；铺满整段的音乐随长度自动循环、截断、淡出。
  • 声音设置是图层：降噪、拉齐、修复、效果、变声、变速、声道、分离、倒放、音量曲线存成参数，作用于整轨或一个范围，渲染时按顺序跑。重的（分离、降噪、响度要两遍）在后台算成缓存文件，按内容哈希命名，撤销不用重算；没算完的部分先放原声。
  • 一条历史：所有改动（含图层、轨道）进同一个撤销栈并持久保存；今天的「版本」不再产生。现有的版本家族迁移成一段音频，旧版本变成历史里的节点。
  • 一句话计划直接产出一次修订（含图层），SessionState.chain 和工具页链条不再需要；计划画在时间线上。
  • 录音写进工程：录到的就是工程的新源，暂停/继续、中断恢复照旧（「之前录的」列表保留）。
  • 导出把主线、轨道、图层一起混合；以后可以加「每轨一个文件」。批量处理走同一条渲染。
  • 存储：源和缓存会比今天多，缓存可清，需要在详情里显示并能清理。

可能出问题的地方，和设计怎么接住

  • 不知道能按住拖：第一次选中后提示一次；「移动」按钮一直在第二位，做同一件事。
  • 工具藏在下一层：第一层只有 4 个，名字就是去处；「说一句」也认工具名（说「降噪」就是降噪）。
  • 小屏、大字：底部工具可以横滑，标签放不下就折成两行；参数层高度有上限，声音至少留一半屏。
  • 用惯了旧版：选区操作原样还在第一层；旧的工具名都能在「说一句」里说；旧版本变成历史节点，不会消失。
  • 很长的音频：全局条、刻度拖动、双指缩放、跳到某个时间、标记；拿着一段时靠边自动滚，太远就用「移动」。
  • 手机上处理慢：设置先生效在前面几十秒，标签上转圈显示进度，别的照常做；导出会等它算完；离开应用也继续算。
  • 误操作：除了删整段音频，一切都能撤销，撤销键在拇指下面。
