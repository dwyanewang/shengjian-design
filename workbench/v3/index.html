试一试

  1. 1在波形上拖动，选一段；点「删除」或「只留」。撤销、重做在播放键左边，按住撤销看全部历史。拖到最左或最右就是开头、结尾，手指不用碰到屏幕边。
  2. 2选一段，按住它拖到别处松手；或点「移动」，再点要放的位置。
  3. 3「声音 → 降噪」：点开就加上了，调力度马上生效，按住「按住听原声」对比。点左上角的「‹ 降噪」回去，设置留着；之后点波形上方的「降噪」标签还能改，或点「去掉」。
  4. 4「添加 → 音乐 → 音频库」：音乐成为下面一轨，有人说话的地方自动变小。点那一轨调它。
  5. 5「说一句」→ 点一个例子：要改的地方画在波形上，勾掉不要的步骤，点「应用」一次改完。
  6. 6右上「导出」：在底部选好，点「导出」，系统存文件。
  7. 7点上面的名字、点时间：这段音频本身的事、播放和查看。任何一层都从栏左端的「‹」回去；从屏幕左右边缘往里滑是系统返回，效果一样（电脑上按 Esc）。

这一版的工作台

工作台就是这段声音。点到什么，底部就是能对它做的事；调的时候声音一直在上面、一直能听；做过的每件事都留在声音上，随时改、随时撤。

  1. 一条底栏，跟着你点的东西变第一行左边是时间，或者「‹ 这一层的名字」；右边固定是撤销、重做、播放。下面是这一层能做的事。往下一层只是这条栏换内容，回去永远是左端的「‹」或系统返回。
  2. 调的东西改了就算，不用确认力度、音量、速度、淡化这些边调边听，回去就留着，撤销一步收回；要去掉就点它自己的「去掉」。只有真正等你拍板的事才有写着字的按钮：应用、导出、完成、放这里、生成。
  3. 两边留给系统声音的开头、结尾在整体视图里离边 40 dp，任何能点能拖的东西离边至少 32 dp；拖到开头、结尾靠吸附，不靠手指够到边。
  4. 一条主线，下面垫声音；没有版本，只有一条历史剪掉就合上，插进就让开；同时响的放在下面的轨道。降噪、音乐、音量是贴在声音上的设置，原始音频不动；要分开保存，用「另存」。

4说明

三条规则（每个画面都照这个做）

底栏

底栏只有一种样子：第一行左边是时间，或者「‹ 这一层的名字」，右边固定是撤销、重做、播放；下面是这一层的内容。往下一层就是这条栏换内容，回去永远是左端的「‹」，系统返回、从屏幕边缘往里滑效果一样。没有居中的标题，没有 ✓ 和 ✕。

设置

设置不是决定：改了就生效、马上能听，回去就留着；在同一层里连续调整算历史里的一步，撤销一次收回；贴在声音上的设置用它自己的「去掉」拿掉。只有真的在等你拍板、又没法边做边看的事才有写着字的按钮：应用（一句话）、导出、完成（录音）、放这里（移动）、生成（朗读、字幕）、删掉 N 处（停顿）、只留这段 / 做铃声（副歌）、保存为音色。不按它直接回去，就是不做。

屏幕两边

两边各 24 dp 归系统的返回手势：从那里开始的滑动不给工作台。任何能点能拖的东西，触点范围离边至少 32 dp（选区圆点、标记、音量曲线的点、全局条、标签、工具、按钮）；整体视图里声音的开头和结尾离边 40 dp。选到开头、结尾靠吸附，手指过了开头或结尾就算到了；放大时拖到离边 64 dp 以内，画面自己往那边滚。工具一行横滑时，第一个和最后一个滑到头都完整露在 32 dp 以内。底栏在系统导航条上面。

覆盖层：今天 16 个，这一版 1 个

规则：只有两种东西可以盖住工作台。① 系统自己的界面：选文件、选保存位置、分享、权限、键盘。② 做了就撤不回的事之前的确认。

  • 确认对话框，一个样式，三处用：删除这段音频；删除克隆的音色（在服务器上，撤不回）；保存失败时仍要离开（改动会丢）。
  • 其余都是系统的：选音频/视频/字幕/封面文件，选保存位置，分享，麦克风和「修改系统设置」权限，键盘。

今天的工作台（EditorScreen、EditorDialogs、EditorExtras、ToolsSheet 四个文件）

  • 14 个底部面板：全部工具、在线音乐库说明、精确时间、片段音量与淡化、片段与接缝、配方管理、版本、选区淡化、插入静音、标记、选区音量、选区「⋯」、改名、导出前的选区提示。
  • 2 个确认框：保存失败时离开、精确时间放弃修改。
  • 另外从工作台会跳到 24 个单独页面（12 个处理工具，加上副歌、节拍、配乐、多轨、串烧、一分钟循环、字幕配音、克隆、一句话计划、导出、导出进度、录音）。这一版是 0 个。

对产品模型的要求（规划用）

  • 一个工程可以有多个源：原始音频、每次录音、朗读、插进来的别的音频、空白，都是工程里的不可变文件；主线的片段可以引用任何一个。跨音频粘贴因此变成普通的时间线修改。
  • 轨道：主线下面最多 7 轨。每轨的片段锚在主线的源帧上（像今天的标记），主线剪掉前面的内容，下面的音乐跟着对齐；铺满整段的音乐随长度自动循环、截断、淡出。
  • 声音设置是图层：降噪、拉齐、修复、效果、变声、变速、声道、分离、倒放、音量曲线存成参数，作用于整轨或一个范围，渲染时按顺序跑。重的（分离、降噪、响度要两遍）在后台算成缓存文件，按内容哈希命名，撤销不用重算；没算完的部分先放原声。
  • 一条历史：所有改动（含图层、轨道）进同一个撤销栈并持久保存；今天的「版本」不再产生。现有的版本家族迁移成一段音频，旧版本变成历史里的节点。
  • 一句话计划直接产出一次修订（含图层），SessionState.chain 和工具页链条不再需要；计划画在时间线上。
  • 录音写进工程：录到的就是工程的新源，暂停/继续、中断恢复照旧（「之前录的」列表保留）。
  • 导出把主线、轨道、图层一起混合；以后可以加「每轨一个文件」。批量处理走同一条渲染。
  • 存储：源和缓存会比今天多，缓存可清，需要在详情里显示并能清理。

可能出问题的地方，和设计怎么接住

  • 不知道能按住拖：第一次选中后提示一次；「移动」按钮一直在第二位，做同一件事。
  • 工具藏在下一层：第一层只有 4 个，名字就是去处；「说一句」也认工具名（说「降噪」就是降噪）。
  • 小屏、大字：底部工具可以横滑，标签放不下就折成两行；参数层高度有上限，声音至少留一半屏。
  • 用惯了旧版：选区操作原样还在第一层；旧的工具名都能在「说一句」里说；旧版本变成历史节点，不会消失。
  • 很长的音频：全局条、刻度拖动、双指缩放、跳到某个时间、标记；拿着一段时靠边自动滚，太远就用「移动」。
  • 手机上处理慢：设置先生效在前面几十秒，标签上转圈显示进度，别的照常做；导出会等它算完；离开应用也继续算。
  • 误操作：除了删整段音频，一切都能撤销，撤销键在拇指下面。
